```
D:\work\office-agent\

├─ scripts\
│  ├─ init_db.sql        # 建 office_oa / office_asset / office_app + 授权
│  └─ smoke_p0.py        # P0 冒烟脚本（可重复执行）
├─ frontend\             # 从 cs-platform 复制的 Vue3 骨架（node_modules 未复制）

└─ docs\                 # 方案 + V1 计划 + 本记录
```
